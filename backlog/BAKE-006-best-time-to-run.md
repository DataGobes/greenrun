# BAKE-006 Best time to run my appliance

**As** a household user
**I want** to know the best time to run my dishwasher
**so that** I save money and help the planet.

## Acceptance criteria

1. Given a day, the system recommends the best start time.
2. The recommendation considers price and green energy.
3. It works for different appliances.
4. It is fast.
